Integração com APIs RESTful

REST é apresentado no material como um estilo arquitetural para criar APIs de forma padronizada e fácil de consumir. As requisições são independentes, recursos são identificados por URLs e JSON é um formato comum de resposta.

↔

Stateless

Cada requisição é independente; o servidor não mantém o estado do cliente entre requisições.

🔗

Recursos e URLs

Um recurso é identificado por uma URL, como /users/1.

{ }

JSON

Formato leve e comum para troca de dados entre sistemas.
